Google Play 데이터 삭제 요청 경로

커뮤니티 프로필 및 데이터 삭제

운영 주체: LOLFLIX
최종 수정일: 2026년 8월 2일

먼저 구분해 주세요

  1. 일반 로컬 데이터 초기화: 로컬 닉네임, 오프라인 게시판, 룬·특성·빌드 등 기기 내부 데이터를 초기화합니다. 온라인 커뮤니티 프로필과 세션은 삭제하지 않습니다.
  2. 이 기기의 커뮤니티 세션 제거: 기기에 저장된 커뮤니티 세션 토큰과 삭제 코드를 제거합니다. 서버 프로필과 작성 콘텐츠는 그대로 남습니다.
  3. 커뮤니티 프로필 및 서버 데이터 삭제: 서버의 익명 커뮤니티 프로필과 연결 데이터를 아래 범위에 따라 삭제·비식별화합니다. 룬·특성·빌드 등 비커뮤니티 로컬 데이터는 지우지 않습니다.

커뮤니티 프로필 삭제 방법

앱을 사용할 수 있는 경우

  1. 앱의 설정에서 커뮤니티 프로필 및 데이터 삭제를 엽니다.
  2. 최신 약관 재동의 없이 안내 범위를 확인한 뒤 앱 내부 삭제 버튼을 누릅니다.
  3. 삭제가 성공하면 이 기기의 커뮤니티 세션도 제거됩니다.

앱을 사용할 수 없는 경우

  1. 익명 프로필 생성 직후 한 번 표시·발급될 때 별도로 보관한 삭제 코드를 준비합니다.
  2. 외부 삭제 코드 입력 페이지를 엽니다.
  3. 삭제 코드를 직접 입력하고 확인 절차를 진행합니다.

삭제 코드는 기기에 저장되지만 현재 Android 설정 화면에서는 다시 표시되지 않습니다. 프로필 소유권을 확인하는 비밀값이므로 지원 이메일이나 공개 게시글에 보내지 마세요. 코드를 분실했고 앱의 인증된 세션에도 접근할 수 없다면 프로필 소유권을 확인하지 못할 수 있습니다.

삭제 시 처리되는 항목

  • 커뮤니티 프로필을 사용 중지하고 이전 세션 토큰과 삭제 코드를 사용할 수 없게 합니다.
  • 닉네임을 제거합니다.
  • 본인이 작성한 게시글·댓글은 본문을 삭제하고 공개되지 않도록 처리합니다.
  • 게시글·댓글의 사용자 연결을 해제합니다.
  • 본인의 추천과 양방향 차단 관계를 제거합니다.
  • 본인이 제출한 신고를 제거하고, 해당 사용자를 대상으로 한 신고의 사용자 연결정보를 비식별화합니다.
  • 버그 신고의 프로필 연결정보와 선택 연락처를 제거합니다.
  • 사용자와 직접 연결된 운영 기록의 연결정보와 상세를 비식별화합니다.

버그 신고의 제목·본문처럼 사용자가 직접 입력한 내용과 앱·기기 정보, 처리 상태는 버그 재현과 처리 이력을 위해 프로필과 분리된 상태로 남을 수 있습니다. 다른 사용자가 작성한 게시글·댓글 등은 임의로 삭제하지 않습니다.

삭제 후 상태

새 커뮤니티 프로필은 자동으로 생성되지 않습니다. 게시판 읽기와 버그 신고는 계속할 수 있으며, 버그 신고를 제외한 다음 커뮤니티 쓰기 시 만 16세 이상 확인, 2026-08-02 약관 동의와 새 닉네임 입력이 필요합니다.

법령상 의무나 남용·보안 대응에 꼭 필요한 최소 기록은 해당 목적에 필요한 범위에서 제한적으로 남을 수 있습니다. 존재하지 않는 고정 보유 기간이나 모든 기록의 즉시 삭제를 약속하지 않습니다.

English summary

Community profile and data deletion

Profile deletion is available in the app without accepting the latest terms, or by submitting the deletion code directly on the external deletion page. The code is shown and issued once immediately after profile creation and is not shown again in current Android settings. Do not email or publicly post it.

Deletion disables the profile, invalidates old credentials, removes or hides the user’s posts and comments, unlinks authorship, and removes recommendations, blocks and submitted reports. Bug-report profile links and contact details are removed, while user-entered report titles, text, app version and some device information may remain without the profile link to the extent operationally necessary.

Reading and bug reporting remain available after deletion. Except for bug reporting, the next community write action requires confirmation that the user is at least 16, acceptance of the 2026-08-02 terms and entry of a new nickname.
