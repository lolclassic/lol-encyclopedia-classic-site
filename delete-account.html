커뮤니티 프로필 및 데이터 삭제

운영 주체: LOLFLIX
최종 수정일: 2026년 9월 27일

먼저 구분해 주세요

  1. 일반 로컬 데이터 초기화: 로컬 닉네임, 오프라인 게시판, 룬·특성·빌드 등 기기 내부 데이터를 초기화합니다. 온라인 커뮤니티 프로필과 세션은 삭제하지 않습니다.
  2. 이 기기의 커뮤니티 세션 제거: 기기에 저장된 커뮤니티 세션 토큰과 삭제 코드를 제거합니다. 서버 프로필과 작성 콘텐츠는 그대로 남습니다.
  3. 커뮤니티 프로필 및 서버 데이터 삭제: 서버의 익명 커뮤니티 프로필과 연결 데이터를 아래 범위에 따라 삭제·비식별화합니다. 룬·특성·빌드 등 비커뮤니티 로컬 데이터는 지우지 않습니다.

커뮤니티 프로필 삭제 방법

앱을 사용할 수 있는 경우

  1. 앱의 설정에서 커뮤니티 프로필 및 데이터 삭제를 엽니다.
  2. 최신 약관 재동의 없이 안내 범위를 확인한 뒤 앱 내부 삭제 버튼을 누릅니다.
  3. 삭제가 성공하면 이 기기의 커뮤니티 세션도 제거됩니다.

앱을 사용할 수 없는 경우

  1. 익명 프로필 생성 직후 한 번 표시·발급될 때 별도로 보관한 삭제 코드를 준비합니다.
  2. 외부 삭제 코드 입력 페이지를 엽니다.
  3. 삭제 코드를 직접 입력하고 확인 절차를 진행합니다.

삭제 코드는 기기에 저장되지만 현재 Android 설정 화면에서는 다시 표시되지 않습니다. 프로필 소유권을 확인하는 비밀값이므로 지원 이메일이나 공개 게시글에 보내지 마세요. 코드를 분실했고 앱의 인증된 세션에도 접근할 수 없다면 프로필 소유권을 확인하지 못할 수 있습니다.

삭제 시 처리되는 항목

  • 커뮤니티 프로필을 사용 중지하고 이전 세션 토큰과 삭제 코드를 사용할 수 없게 합니다.
  • 닉네임을 제거합니다.
  • 본인이 작성한 게시글·댓글은 본문을 삭제하고 공개되지 않도록 처리합니다.
  • 게시글·댓글의 사용자 연결을 해제합니다.
  • 본인의 추천과 양방향 차단 관계를 제거합니다.
  • 본인이 제출한 신고를 제거하고, 해당 사용자를 대상으로 한 신고의 사용자 연결정보를 비식별화합니다.
  • 버그 신고의 프로필 연결정보와 선택 연락처를 제거합니다.
  • 사용자와 직접 연결된 운영 기록의 연결정보와 상세를 비식별화합니다.

버그 신고의 제목·본문처럼 사용자가 직접 입력한 내용과 앱·기기 정보, 처리 상태는 버그 재현과 처리 이력을 위해 프로필과 분리된 상태로 남을 수 있습니다. 다른 사용자가 작성한 게시글·댓글 등은 임의로 삭제하지 않습니다.

삭제 후 상태

새 커뮤니티 프로필은 자동으로 생성되지 않습니다. 게시판 읽기·작성, 댓글, 신고, 버그 신고 등 온라인 커뮤니티를 다시 이용하려면 만 18세 이상 확인과 2026-09-27 약관 동의가 필요하며, 새 프로필을 만들 때 새 닉네임을 입력해야 합니다. 프로필 삭제와 개인정보 관련 문의는 새 약관 동의 없이 계속할 수 있습니다.

법령상 의무나 남용·보안 대응에 꼭 필요한 최소 기록은 해당 목적에 필요한 범위에서 제한적으로 남을 수 있습니다. 존재하지 않는 고정 보유 기간이나 모든 기록의 즉시 삭제를 약속하지 않습니다.

불법·유해 콘텐츠 신고

앱의 신고 기능으로 운영자 검토를 요청할 수 있습니다. 긴급한 개인정보 노출은 지원 이메일에 콘텐츠 식별정보와 함께 알려 주세요.

English summary

Community profile and data deletion

Profile deletion is available in the app without accepting the latest terms, or by submitting the deletion code directly on the external deletion page. The code is shown and issued once immediately after profile creation and is not shown again in current Android settings. Do not email or publicly post it.

Deletion disables the profile, invalidates old credentials, removes or hides the user’s posts and comments, unlinks authorship, and removes recommendations, blocks and submitted reports. Bug-report profile links and contact details are removed, while user-entered report titles, text, app version and some device information may remain without the profile link to the extent operationally necessary.

Further online community use, including reading and bug reporting, requires confirmation that the user is at least 18 and acceptance of the 2026-09-27 terms. A new profile requires a new nickname. Profile deletion and privacy inquiries remain available without reacceptance.

日本語の案内

コミュニティのプロフィールとデータの削除

運営者：LOLFLIX。最終更新日：2026年9月27日。

3つの操作の違い

  1. 一般のローカルデータの初期化：ローカルのニックネーム、オフライン掲示板、ルーン・マスタリー・ビルドなどの端末内データを初期化します。オンラインコミュニティのプロフィールとセッションは削除しません。
  2. この端末のコミュニティセッションの削除：端末に保存されたセッショントークンと削除コードを削除します。サーバーのプロフィールと投稿内容は残ります。
  3. プロフィールとサーバーデータの削除：サーバーのコミュニティプロフィールと関連データを、以下の範囲で削除・非識別化します。コミュニティ以外のルーン・マスタリー・ビルドなどのローカルデータは削除しません。

アプリを使える場合

  1. アプリの設定から、コミュニティのプロフィールとデータを削除する項目を開きます。
  2. 最新規約への再同意は不要です。削除範囲を確認し、アプリ内の削除ボタンを押します。
  3. 削除が成功すると、この端末のコミュニティセッションも削除されます。

アプリを使えない場合

  1. プロフィール作成直後に一度だけ表示・発行されたときに、別途保管した削除コードを用意します。
  2. 外部の削除コード入力ページを開きます。
  3. 削除コードをそのページに直接入力し、確認手順を進めます。

削除コードは端末に保存されますが、現在の Android 設定画面には再表示されません。プロフィールの所有者であることを確認する秘密の値なので、メールや公開投稿に送らないでください。コードを紛失し、アプリの認証済みセッションにもアクセスできない場合、所有者であることを確認できない可能性があります。

削除による処理

  • プロフィールを無効化し、以前のセッショントークンと削除コードを使用できなくします。
  • ニックネームを削除します。
  • 本人の投稿・コメントの本文を消去して非公開にし、投稿者との紐付けを解除します。
  • 本人による投稿への推薦と、双方向のブロック関係を削除します。
  • 本人が提出した通報を削除し、本人を対象とする通報のユーザーとの紐付け情報を非識別化します。
  • 不具合報告のプロフィールとの紐付けと任意の連絡先を削除します。
  • 本人に直接紐付く運営記録の関連情報と詳細を非識別化します。

不具合報告のタイトル・本文など、利用者が入力した内容、アプリ・端末情報、処理状態は、不具合の再現調査や対応履歴のため、プロフィールとの紐付けを解除した状態で残る場合があります。他の利用者の投稿やコメントは任意に削除しません。

削除後の状態

新しいプロフィールは自動で作成されません。閲覧、投稿、コメント、通報、不具合報告などのオンラインコミュニティを再び利用するには、18歳以上であることの確認と 2026-09-27 版の利用規約への同意が必要です。新しいプロフィールには新しいニックネームを入力します。プロフィール削除とプライバシーに関する問い合わせは、再同意せずに引き続き利用できます。
