공개 이슈에 민감한 정보를 적지 마세요.

문의 제목에는 “제품”, “개인정보”, “권리”, “보안” 중 해당 유형을 표시하고, 비공개 후속 연락이 필요하다는 사실만 남겨 주세요.

  • API 키, 비밀번호, 인증 코드, 서명 키 또는 인증서 원본
  • 사업자·기업 식별번호, 결제 정보 또는 신분증 사본
  • 주민등록번호, 주소, 전화번호 등 민감한 개인정보
  • 공개하면 안 되는 권리 증빙 또는 보안 취약점 세부 정보

일반 문의에 포함할 내용

  • 문의 목적과 영향을 받는 제품 화면 또는 웹페이지
  • 문제를 재현하거나 내용을 검토할 수 있는 최소한의 설명
  • 사용 중인 Android 버전과 앱 화면 경로(제품 문제인 경우)
  • 비공개 답변이 필요한지 여부
