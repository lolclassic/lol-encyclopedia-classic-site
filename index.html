26.19.5 · Browser beta preview

Explore the PC Beta.

The PC Beta uses the app's current encyclopedia interface to browse 72 champions, purchasable items, masteries, spells, runes, and 26.19 news. Champion details include editorial suggested builds and explanations of linked skill effects. Cataloged voice lines play locally where available, with their source labels. Settings and saved reference choices stay in the browser.

Community and online video are not connected in this browser preview; the Android app handles the online community.

26.19.5 development build

A historical archive and community in one app.

The app includes searchable champion, item, rune, and terminology references. Posts, comments, recommendations, reporting, blocking, and bug reports are handled by an HTTPS online service.

Pseudonymous community

The 26.19.5 Canary community requires age 18+ confirmation and acceptance of its terms before use. It supports posts, comments, recommendations, reports, and blocks.

06

Three app languages

Choose Korean, Japanese, or English for the interface and reference descriptions. The voice language has a separate setting and source labels.

Suggested Classic builds

Each of the 72 champions has an editorial example of items, runes, masteries, and skill order. These are reference suggestions, not measured pick rates or win rates.

Data boundary

Local reference data stays separate from the online community.

App settings, masteries, builds, and rune pages remain on the device. Community requests use LOLFLIX over HTTPS. Optional post translation is being tested in 26.19.5 Canary QA; the production translation Worker's server-side switch is configured off. When enabled and requested, LOLFLIX's Cloudflare Worker sends stored post titles, bodies, and target language to Google Gemini API using a billing-linked project. Canary has request-count limits, but these do not guarantee zero cost. Privacy details

Riot API status

Production Riot API features are not live yet.

Limited in-app current-player lookup remains disabled until LoL Encyclopedia Classic (Application 861480) receives the applicable Riot Production approval. For expanded current-player statistics and match history, the Android app may open Rift Archive (Application 868824), a separately registered product. Each product will use only its own Production API key and server-side backend if approved.
