1. 서비스

롤 백과사전 클래식은 과거 리그 오브 레전드 정보를 살펴보는 비공식 Android 참고 앱입니다. 로컬 아카이브와 LOLFLIX가 운영하는 온라인 커뮤니티의 게시글·댓글·추천·게시글 신고·버그 신고·사용자 차단 및 차단 해제 기능을 제공합니다.

Riot API 기반 전적 검색은 현재 제공하지 않으며 업데이트 예정 기능입니다. 이 프로젝트는 Riot Games의 공식 제품이나 승인 제품이 아닙니다.

2. 커뮤니티 이용 자격과 동의

온라인 커뮤니티는 만 18세 이상만 이용할 수 있습니다. 이메일·비밀번호 회원가입이나 실명 계정은 없으며, 안정적인 익명 사용자 식별정보와 사용자가 정한 닉네임으로 프로필을 유지합니다.

게시판 읽기·작성, 댓글, 추천, 신고, 사용자 차단, 버그 신고를 포함한 온라인 커뮤니티 이용에는 만 18세 이상 확인과 2026-09-27 약관 동의가 필요합니다. 기존 이용자도 계속 이용하려면 새 약관에 다시 동의해야 합니다. 커뮤니티 프로필 및 데이터 삭제와 개인정보 관련 문의는 새 약관 동의 없이 할 수 있습니다.

삭제 코드는 익명 프로필 생성 직후 한 번 표시·발급되어 기기에 저장됩니다. 현재 Android 설정 화면에서는 다시 표시되지 않으므로 처음 표시될 때 안전하게 보관해야 합니다.

4. 사용자 콘텐츠와 안전 기능

사용자는 게시한 콘텐츠에 책임을 집니다. 서비스 운영에 필요한 범위에서 LOLFLIX가 게시글·댓글과 신고·버그 신고를 저장·표시·전송하고 운영 조치를 위해 처리하는 것을 허용합니다.

게시글 신고는 운영자 검토로 전달됩니다. 사용자는 다른 작성자를 차단하거나 차단을 해제하고 차단 목록을 관리할 수 있습니다. 차단은 표시 닉네임이 아니라 서버의 안정적인 익명 사용자 식별정보를 기준으로 적용되므로 닉네임이 바뀌어도 유지됩니다.

LOLFLIX는 신고 또는 자체 확인에 따라 콘텐츠를 숨기거나 복원·수정·삭제하고 반복 위반 프로필의 쓰기를 제한하거나 이용을 정지할 수 있습니다.

26.19.5 개발 빌드의 선택형 게시글 번역은 현재 Canary QA에서 시험 중이며, 운영용 번역 Worker의 서버 측 기능은 비활성 설정입니다. 기능이 활성화된 환경에서 다른 이용자가 게시글 번역을 요청하면 제목·본문과 번역 언어가 Cloudflare를 거쳐 결제 계정이 연결된 Google Gemini API 프로젝트에 전달될 수 있습니다. Google은 유료 서비스의 입력·출력을 제품 개선에 사용하지 않는다고 명시하며, 남용 방지·보안·법적 의무를 위해 제한된 기간 기록할 수 있습니다. 게시글에 민감정보, 기밀정보 또는 개인정보를 포함하지 마세요. 자세한 내용은 개인정보처리방침의 선택형 게시글 번역을 확인하세요.

5. 삭제

커뮤니티 프로필과 서버 데이터는 최신 약관 재동의 없이 앱 내부에서 삭제하거나 계정·데이터 삭제 안내에 따라 외부 페이지에 삭제 코드를 제출하여 삭제할 수 있습니다. 일반 로컬 데이터 초기화와 이 기기의 커뮤니티 세션 제거는 서버 프로필 삭제와 다른 작업입니다.

프로필 삭제 시 본인 게시글·댓글은 본문이 삭제되거나 공개되지 않도록 처리되고 사용자 연결이 해제되며, 추천·차단 관계·본인이 제출한 신고가 제거됩니다. 버그 신고의 프로필 연결과 연락처는 제거되지만 사용자가 직접 입력한 제목·본문, 앱 버전과 기기 정보 일부는 운영상 필요한 범위에서 프로필과 분리된 상태로 남을 수 있습니다. 다른 사용자가 작성한 데이터와 룬·특성·빌드 같은 비커뮤니티 로컬 데이터는 삭제하지 않습니다.
