# 롤 백과사전 클래식

시즌 3·4 시절의 챔피언, 아이템, 특성, 소환사 주문과 룬을 현대 Android에서 살펴보는 LOLFLIX의 비공식 참고 앱입니다.

## 현재 기능
- 클래식 챔피언 60명
- 아이템 190개, 특성 56개, 소환사 주문 16개
- 30개 룬 소켓과 20개 룬 페이지
- 닉네임 기반 익명 온라인 자유게시판·댓글·신고·버그 신고
- 운영자 앱을 통한 콘텐츠 조정

환경설정, 특성, 빌드와 룬 편성은 기기 내부에 저장됩니다. 커뮤니티 데이터는 HTTPS로 LOLFLIX 서비스에 전송됩니다.
