1. 적용 범위

이 방침은 롤 백과사전 클래식의 공개 제품 사이트와 현재 오프라인 Android 앱에 적용됩니다. 아직 제공하지 않는 Riot API 조회, 사용자 계정, 공유 커뮤니티, 광고 및 분석 기능은 현재 처리 범위에 포함되지 않습니다.

2. 현재 앱의 개인정보 처리

현재 Android 앱은 회원가입을 요구하지 않으며, LOLFLIX 서버로 개인정보를 전송하거나 공유하지 않습니다. 앱은 Android 인터넷 권한을 요청하지 않고 광고·분석·위치 추적 SDK를 포함하지 않습니다.

사용자가 입력한 닉네임, 기기 내 테스트 게시글·댓글·추천, 환경 및 음성 설정, 특성 투자, 빌드, 룬 메모와 룬 페이지 편성은 해당 기기의 WebView 앱 전용 로컬 저장소에서만 처리됩니다. 이 정보는 다른 사용자에게 전송되지 않습니다.

3. 권한과 외부 링크

현재 앱은 연락처, 카메라, 마이크, 사진, 오디오, 위치, 공유 저장소 등 민감한 Android 권한을 요청하지 않습니다. 앱 내부 WebView는 앱에 포함된 로컬 자료만 표시합니다.

사용자가 개인정보처리방침, 이용약관, 문의 또는 Riot Games 공식 출처 버튼을 직접 선택한 경우에만 미리 허용된 HTTPS 주소를 기기의 외부 브라우저로 전달합니다. 외부 서비스의 정보 처리는 각 서비스의 정책을 따릅니다.

4. 보관과 삭제

로컬 데이터는 사용자가 앱의 “저장 데이터 초기화” 기능을 실행하거나, Android 설정에서 앱 데이터를 삭제하거나, 앱을 제거할 때까지 기기에 남습니다. 현재 앱은 서버 계정을 만들지 않으므로 별도의 서버 계정 삭제 절차가 없습니다.

앱 데이터는 Android 자동 백업 및 기기 간 데이터 이전 대상에서 제외됩니다.

5. 이 공개 사이트

이 정적 사이트에는 LOLFLIX가 운영하는 계정 시스템, 입력 폼, 쿠키 기반 광고 또는 분석 추적기가 없습니다. GitHub Pages 등 호스팅 제공자는 자체 정책에 따라 IP 주소, 브라우저 정보, 요청 시각과 같은 표준 기술 요청 정보를 처리할 수 있습니다.

6. 향후 온라인 기능

Riot API 조회, 서버 계정, 공유 커뮤니티, 광고·분석 또는 기타 온라인 기능이 추가되는 경우 공개 전에 이 방침과 Google Play 데이터 보안 선언을 갱신합니다. 갱신본에는 실제 처리 항목, 목적, 보관 기간, 공유, 보안 조치와 삭제 절차를 구체적으로 기재합니다.

7. 문의

개인정보 관련 문의는 공개 문의 안내에 표시된 경로로 시작할 수 있습니다. 민감한 증빙, 비밀번호, API 키, 서명 자료, 주민등록번호 등 비공개 정보를 공개 이슈에 게시하지 마세요.

Google Play에 공개적으로 표시할 전용 지원 이메일은 계정 소유자의 최종 확인 후 별도로 게시됩니다.
