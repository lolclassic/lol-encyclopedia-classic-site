1. 적용 범위

이 방침은 롤 백과사전 클래식 Android 앱, LOLFLIX 온라인 커뮤니티 서비스와 공개 제품 사이트에 적용됩니다. 백과사전·룬·특성·빌드 같은 비커뮤니티 기능과 온라인 커뮤니티의 데이터 처리는 서로 구분됩니다.

2. 처리하는 데이터

기기 내부

  • 환경설정, 특성 투자, 빌드, 룬 메모와 룬 페이지 편성, 오프라인 게시판 데이터
  • 앱 화면 상태와 로컬 캐시
  • 온라인 커뮤니티 세션 토큰, 삭제 코드와 현재 사용자 정보

룬·특성·빌드 등 비커뮤니티 로컬 데이터는 LOLFLIX 서버로 전송되지 않습니다. 커뮤니티 세션 정보는 온라인 기능을 사용할 때 서버와 통신하는 데 사용됩니다.

온라인 커뮤니티 서버

  • 안정적인 익명 사용자 식별정보, 닉네임과 동의한 약관 버전
  • 인증 토큰과 삭제 코드의 해시값
  • 게시글, 댓글, 추천, 게시글 신고, 차단 관계와 운영 처리 상태
  • 버그 신고 제목·본문, 앱 버전, 기기·운영체제·브라우저 식별 문자열과 선택 연락처
  • 서비스 보안과 남용 방지를 위한 요청 시각 및 표준 기술 로그

이메일이나 실명으로 회원가입하지 않으며, 인증 토큰과 삭제 코드의 원문은 서버에 저장하지 않습니다. Cloudflare 등 인프라 제공자는 서비스 제공과 보안 목적으로 IP 주소 같은 표준 네트워크 요청 정보를 자체 정책에 따라 처리할 수 있습니다. 앱은 정확한 위치, 연락처 목록, 사진, 카메라, 마이크 또는 결제정보를 요구하지 않습니다.

2-1. 선택형 게시글 번역

26.19.5 개발 빌드의 선택형 게시글 번역은 Canary QA에서 시험 중이며, 운영용 번역 Worker의 서버 측 기능은 비활성 설정입니다. 기능이 활성화된 환경에서 이용자가 자유게시판 게시글의 번역 버튼을 누르면 첫 이용 시 안내 동의 후 앱은 게시글 ID와 선택한 번역 언어를 HTTPS로 LOLFLIX의 Cloudflare 번역 Worker에 보냅니다. 이 서비스는 저장된 게시글의 제목·본문을 읽어 결제 계정이 연결된 Google Gemini API 프로젝트에 번역을 요청합니다. Google은 유료 서비스의 입력·출력을 제품 개선에 사용하지 않는다고 명시하며, 남용 방지·보안·법적 의무를 위해 제한된 기간 기록할 수 있습니다. 다른 이용자가 번역을 요청할 수도 있으므로 게시글 제목·본문에 민감정보, 기밀정보 또는 개인정보를 포함하지 마세요. 번역은 선택 사항이며 원문을 계속 볼 수 있습니다. 번역을 요청하지 않아도 게시글 열람·작성과 댓글 기능을 사용할 수 있습니다. 자세한 내용은 Gemini API 추가 약관과 요금 및 데이터 이용 안내를 참고하세요.

3. 처리 목적

  • 익명 커뮤니티 프로필과 게시글·댓글·추천 기능 제공
  • 게시글 신고 접수, 사용자 차단·차단 해제와 차단 목록 관리
  • 신고 검토, 콘텐츠 숨김·복원·수정·삭제와 이용 제한
  • 버그 조사, 사용자 문의와 품질 개선
  • 남용·자동화 공격·보안 사고 예방과 대응
  • 법적 의무와 분쟁 대응

4. 제3자 제공과 처리 위탁

LOLFLIX는 사용자 데이터를 판매하거나 맞춤형 광고 목적으로 공유하지 않습니다. 선택형 게시글 번역 기능이 활성화된 환경에서 사용자가 번역을 요청하면 2-1항에 설명한 대로 게시글 제목·본문과 번역 언어가 Google Gemini API로 전달됩니다. 온라인 커뮤니티는 Cloudflare Workers와 D1을 사용하고 공개 사이트는 GitHub Pages를 사용합니다. 법령 또는 권리 보호에 필요한 경우 법적 근거에 따라 정보를 제공할 수 있습니다.

5. 보안

앱과 서버 간 통신은 HTTPS를 사용합니다. 서버는 인증 토큰과 삭제 코드 대신 그 해시값을 저장합니다. 운영자 비밀과 서명 키는 일반 앱이나 공개 저장소에 포함하지 않습니다.

6. 보관과 삭제

온라인 커뮤니티 데이터는 서비스 제공, 운영, 보안과 분쟁 대응에 필요한 동안 처리합니다. 법령상 의무나 남용·보안 대응에 꼭 필요한 최소 기록은 해당 목적에 필요한 범위에서 제한적으로 남을 수 있습니다.

커뮤니티 프로필 삭제가 완료되면 프로필을 사용 중지하고 이전 세션 토큰과 삭제 코드를 사용할 수 없게 하며 닉네임을 제거합니다. 본인이 작성한 게시글·댓글은 본문을 비우고 공개되지 않도록 처리하며 작성자 연결을 해제합니다. 추천과 양방향 차단 관계, 본인이 제출한 신고는 제거되고, 해당 사용자를 대상으로 한 신고 및 사용자와 연결된 운영 기록은 연결정보를 비식별화합니다.

버그 신고에서는 프로필 연결정보와 선택 연락처를 제거합니다. 다만 버그 재현과 처리 이력을 위해 사용자가 직접 입력한 제목·본문, 앱·기기 정보와 처리 상태는 프로필과 분리된 상태로 남을 수 있습니다.

다른 사용자가 작성한 데이터는 임의로 삭제하지 않으며 룬·특성·빌드 같은 비커뮤니티 로컬 데이터도 커뮤니티 프로필 삭제 대상이 아닙니다. 삭제 뒤 새 프로필은 자동 생성되지 않고, 다음 온라인 커뮤니티 이용 시 만 18세 이상 확인과 2026-09-27 약관 동의가 필요하며, 새 프로필을 만들 때 새 닉네임을 입력해야 합니다.

삭제 코드는 익명 프로필 생성 직후 한 번 표시·발급되어 기기에 저장됩니다. 현재 Android 설정 화면에서는 다시 표시되지 않으므로 처음 표시될 때 별도로 보관해야 합니다. 삭제 방법과 세 가지 데이터 관리 동작의 차이는 커뮤니티 프로필 및 데이터 삭제 안내에서 확인할 수 있습니다.

7. 아동·청소년과 약관 동의

온라인 커뮤니티는 만 18세 이상만 이용할 수 있습니다. 게시판 읽기·작성, 댓글, 추천, 신고, 사용자 차단 및 버그 신고를 포함한 온라인 커뮤니티 이용에는 만 18세 이상 확인과 2026-09-27 약관 동의가 필요합니다. 기존 이용자도 계속 이용하려면 새 약관에 다시 동의해야 합니다. 프로필 및 데이터 삭제와 개인정보 관련 문의는 새 약관 동의 없이 할 수 있습니다.

8. 공개 사이트

이 정적 사이트에는 LOLFLIX가 운영하는 로그인, 광고 쿠키 또는 행동 분석 추적기가 없습니다. GitHub Pages는 자체 정책에 따라 표준 요청 정보를 처리할 수 있습니다.

Privacy Policy summary

Another reader may request translation of a post, so do not include sensitive, confidential, or personal information in post titles or bodies. Profile deletion disables the profile, invalidates prior credentials, removes or hides the user’s posts and comments, unlinks authorship, and removes recommendations, blocks and submitted reports.
