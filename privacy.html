Public policy

Privacy Policy

Operator: LOLFLIX
Effective date and last updated: July 26, 2026

1. Scope

This policy applies to this public product website and the current closed-test Android prototype of LoL Encyclopedia Classic. It describes the product as it exists today. Planned online community and Riot API features are not currently available.

2. Data processed by the current prototype

The current Android prototype does not require an account and does not transmit personal information to a LOLFLIX server. User-created test posts, preferences, builds, mastery selections, and rune-page selections are stored locally on the user's device.

The current build does not contain advertising or analytics SDKs and does not request contacts, camera, microphone, photos, audio, location, or shared-storage permissions.

3. This website

This static website does not use LOLFLIX-operated analytics, advertising trackers, account systems, or contact forms. Hosting infrastructure may process standard technical request data such as IP address, browser information, and request time according to the hosting provider's own policies.

4. Storage and deletion

Local prototype data remains on the device until the user clears saved data within the app, clears the app's Android storage, or uninstalls the app. Because the current prototype does not create a server account, there is no separate server-side account deletion process.

5. Planned online features

If live Riot API lookups, accounts, or a shared community are introduced, this policy will be updated before those features become publicly available. The update will describe the specific data, purpose, legal basis where applicable, retention period, sharing, security controls, and user deletion procedures.

6. External links

The site may link to GitHub, Riot Games, and other external services. Their handling of information is governed by their own privacy policies.

7. Contact

Privacy questions can be sent through the public project contact route described on the Contact page. A dedicated privacy contact address will be published before any public release that processes personal information on LOLFLIX servers.

개인정보처리방침 요약

현재 비공개 테스트용 Android 프로토타입은 회원가입을 요구하지 않으며 개인정보를 LOLFLIX 서버로 전송하지 않습니다. 시험용 게시글, 설정, 빌드, 특성 및 룬 페이지 정보는 사용자의 기기 안에만 저장됩니다.

현재 빌드에는 광고·분석 SDK가 없고 연락처, 카메라, 마이크, 사진, 오디오, 위치 또는 공용 저장소 권한을 요청하지 않습니다. 사용자는 앱의 저장 데이터 초기화, Android 앱 데이터 삭제 또는 앱 제거를 통해 로컬 데이터를 삭제할 수 있습니다.

Riot API 조회, 계정 또는 공용 커뮤니티 기능이 추가될 경우 공개 전에 실제 처리 내용과 보유 기간, 삭제 절차를 반영하여 이 방침을 갱신합니다.
